# PlayZone - Campus Sports Booking System

A complete Python/Tkinter desktop application for booking campus sports facilities.

## Features
- User Portal: Sign up, login, view live availability, and reserve grounds.
- Admin Dashboard: Manage bookings, approve/reject requests, view stats.
- Event Locking: Blocks reservations during college events.
- Database: SQLite integration for secure data storage.

## How to Run
1. Install requirements: `pip install pillow`
2. Run the app: `python login.py`
